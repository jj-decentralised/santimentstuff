# Development Notes

## Design Guidelines

1. **Aesthetic**: Inspired by WSJ - sleek, plain white design, colors used intentionally

## Data Requirements

2. **Data Coverage**: Capture data as wide as possible, updated as frequently as possible

## Testing Requirements

3. **API Testing**: Test all data pulls before committing - ensure API access and data rendering is accurate

4. **Deployment Gate**: Do not deploy until testing is done rigorously

5. **Slug Validation**: When slug configs don't match, flag it in testing itself and don't deploy
